# Happy-Birthday-Zoya

## Introduction

**Happy Birthday Zoya** is an interactive birthday website I created as a special gift for my best friend’s 18th birthday. Instead of giving her only a normal card, I wanted to make something more personal, interactive, and memorable.

The website uses a cute navy-blue, her favorite color, night sky theme with stars, clouds, pink accents, animations, and small surprises throughout the experience.

## Features

- Interactive “Are you ready?” opening screen
- Funny Yes and No button interaction
- No button becomes smaller every time it is clicked
- Different messages appear after every No click
- Animated photo gallery with personal memories
- Photo cards can be flipped to reveal small messages
- Interactive envelope that opens a birthday letter
- Confetti and sparkle animations
- Birthday countdown that locks the website outside of October 3
- Website automatically unlocks every year on October 3
- Displays the next birthday number and countdown
- QR code access for the physical birthday card

## Usage

Visit the live site:

👉 [https://anpham09.github.io/Happy-Birthday-Zoya/](https://anpham09.github.io/Happy-Birthday-Zoya/)

The website is designed to be opened through a QR code included with the birthday gift.

Outside of October 3, the website displays a countdown until the next birthday. On October 3, the birthday website automatically unlocks.

## Story

I wanted to create something that could stay longer than a normal birthday gift.

Since my friend’s birthday is October 3, I designed the website so that it becomes available only on that day. After her birthday ends, the website locks again and starts counting down to the next October 3.

The website begins with a small challenge asking if she is ready. Of course, saying “No” is not really an option because the No button slowly becomes smaller every time she clicks it.

After choosing Yes, she can look through photos and memories, open a digital birthday letter, and reach a final birthday surprise.

I hope that every year when October 3 comes again, she can return to the same website and remember her 18th birthday and the memories behind this gift.

## Obstacles

One of the biggest challenges was making the website work consistently both locally and after publishing it through GitHub Pages. Some images and updated CSS or JavaScript files worked correctly on my computer but behaved differently after deployment.

I also had to carefully work with animations and JavaScript interactions, including the shrinking No button, photo card animations, countdown system, screen transitions, and birthday lock.
